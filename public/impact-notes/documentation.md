# Documentation
**Status:** Frontier

AI is excellent at generating documentation from code: API references, README files, inline comments, and tutorials. The gap is closing fast for technical docs. However, documentation that explains "why" decisions were made and guides users through complex workflows still benefits from human authorship.

## Latest
- **2026-08-20**: Researchers studying 557 coding-agent sessions found that agents mostly used instructions and working notes. The researchers saw no sequence in which an agent explicitly checked its work against the documentation. For authors, that makes a concrete test or acceptance criterion worth recording alongside a requirement. [Agent-documentation study](https://arxiv.org/abs/2608.20195)
- **2026-08-13**: The MOOSEDev preprint tested a way to record why a team made a decision and which later decision replaced it. In a benchmark, the system recovered superseded decisions more reliably than the vector-search baseline. [Project-memory study](https://arxiv.org/abs/2608.13662)
